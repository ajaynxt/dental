# AJAYNXT Dental Design Studio

Three interactive dental clinic concepts in one responsive website.

## GitHub Pages
1. Upload all files to the repository root.
2. Settings → Pages → Deploy from `main` and `/ (root)`.
3. Add DNS CNAME: `dental` → `ajaynxt.github.io`.
4. Custom domain: `dental.ajaynxt.com`.

Photos are loaded from Pexels CDN and remain subject to the Pexels license.
